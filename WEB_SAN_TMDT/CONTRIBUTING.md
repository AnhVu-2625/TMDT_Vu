# CONTRIBUTING.md

## Hướng dẫn Đóng góp

Cảm ơn bạn đã quan tâm đến MartHub! Tôi rất hân hạnh nhận được những đóng góp của bạn.

### Quy trình

1. **Fork** repository
2. **Clone** vào máy của bạn
3. **Create** branch mới (`git checkout -b feature/AmazingFeature`)
4. **Commit** thay đổi (`git commit -m 'Add some AmazingFeature'`)
5. **Push** đến branch (`git push origin feature/AmazingFeature`)
6. **Open** Pull Request

### Coding Standards

- Sử dụng ESLint
- Viết clean code
- Thêm comments cho code phức tạp
- Test trước khi submit

### Issue Report

Khi báo cáo issue, hãy cung cấp:
- Mô tả rõ ràng
- Steps to reproduce
- Expected behavior
- Screenshots (nếu có)

Cảm ơn đã đóng góp! 🎉
